Vim Keys

Tastenbelegung

Wird auf die Standardbelegung (wie Vimium C) angewendet. map <taste> <befehl>, unmap <taste>, unmapAll, # für Kommentare. Tasten: j, gg, F, <c-s-f>, <a-c-f>, <esc>, <f1>.

    Ausnahmen

    Auf passenden Seiten gehen die genannten Tasten direkt an die Seite. Leere Tastenliste = auf der Seite ganz aus.
    Muster: reddit.com (Host), *.reddit.com (mit Subdomains), https://example.com/pfad (Präfix, * als Platzhalter), ^… (regulärer Ausdruck).
    Tasten: jk0123456789, Sondertasten wie <c-j>.
